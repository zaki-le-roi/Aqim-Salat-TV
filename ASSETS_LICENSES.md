# Asset licenses

The build script attempts to fetch the single general-purpose mosque adhan listed below. If the download or validation fails, it generates a short original alert tone with FFmpeg. The downloaded media is generated in the Android build directory and is not committed as a binary to this source repository.

| Build asset | Generated file | Source / creator | License and conditions | Current repository status |
|---|---|---|---|---|
| General adhan | `android/app/src/main/res/raw/adhan_default.ogg` | [Adhan in Shalqar mosque.webm](https://commons.wikimedia.org/wiki/File:Adhan_in_Shalqar_mosque.webm), author Esetok | CC BY-SA 4.0. Credit: “Adhan in Shalqar mosque” by Esetok, Wikimedia Commons. Link the license and indicate FFmpeg audio extraction/format conversion. Adapted audio must be shared under CC BY-SA 4.0 or a compatible license. | Scripted download; not yet confirmed in a successful CI build |
| Fallback alert | `android/app/src/main/res/raw/aqim_alert_tone.ogg` | Original sine-wave tone generated by FFmpeg | Original generated audio; no third-party recording or attribution | Generated only when the adhan download/validation fails |

The Commons source page identifies the file as an adhan recording, duration 2 min 35 sec, by Esetok, under CC BY-SA 4.0. The recording has not yet been downloaded and auditioned in this environment. The script validates the downloaded audio stream and duration, not the spoken content.

No verified Fajr-specific recording containing “الصلاة خير من النوم” has been added. No five-reciter library has been sourced. Those requirements remain open; no famous or commercially protected reciter recordings are used.
